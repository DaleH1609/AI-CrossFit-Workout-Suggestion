Schedule Builder — Which approach feels right?

Three ways to replace the drag-and-drop grid. Click one to select it.

A

Click-to-toggle Grid + Edit Panel

Keep the week grid, but replace drag with simple clicks. Click an empty cell to instantly add a slot. Click an active slot to open an edit panel on the right — no popover, more space for details. Feels like a spreadsheet but without the drag frustration.

B

Day-by-Day List Builder

Each day is its own section. Click "Add slot" to append a new time slot — pick the time and class type from dropdowns, set capacity. Slots appear as cards below. No grid, no dragging — pure form-based. Like building a list for each day.

C

Hybrid — Day columns, time rows, click only

Keep the 7-column week view but make the whole grid click-based. Clicking an empty cell adds a slot and immediately opens an inline edit row (no popover, no side panel — edits appear right in the cell row). Clicking an active slot opens the same inline edit. No drag, no popover positioning issues.
